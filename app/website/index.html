Sylor

Your AI coding workspace, on your machine.

A chat-first desktop app that plans, edits, and runs code with you — bring your own model, keep your API keys local, and watch it work with live preview and a safe, step-by-step agent loop.

This build is self-signed, so Windows may show a “Windows protected your PC” screen the first time. Click More info → Run anyway to continue — the source is public on GitHub.

Built to work the way you do

Everything runs locally in a native desktop app. No cloud lock-in, no telemetry — your code and keys stay on your machine.

Local-first & private

Your files, chats, and API keys never leave your computer. Sylor is sandboxed to the folder you open.

Bring your own model

Point Sylor at Ollama or any OpenAI-compatible gateway — your key, your provider, your choice of model.

Skills & connectors

Extend it with disk-authored Skills and MCP servers — add tools and playbooks the model can invoke on demand.

Live preview & safe loop

See changes render as they happen, while a step-by-step agent loop keeps every write and command behind your approval.

Up and running in a minute

Download, install, and open Sylor — just like any other Windows app.

Download

Grab Sylor-Setup.exe using the button above.

Open it

Double-click the file in File Explorer. If SmartScreen appears, choose More info → Run anyway.

Install & launch

Follow the installer, then open Sylor from the Start menu or desktop.
